# 🛡️ Insurance RAG Chatbot

A chatbot that answers questions about insurance policies using **Retrieval-Augmented Generation (RAG)**. It finds the most relevant policy records with vector search and lets Gemini write the answer.

   🔗 **Live demo:** https://rag-chat-bot-dp26.vercel.app/

## ✨ Features

- Semantic search over insurance records with MongoDB Atlas Vector Search
- Answers generated by Google Gemini, based only on retrieved data
- React chat UI with a typing effect
- Automatic retry and fallback model when Gemini is busy

## 🧰 Tech Stack

| Part | Technology |
|------|------------|
| Frontend | React, Tailwind CSS, Axios |
| Backend | Node.js, Express |
| Database | MongoDB Atlas (Vector Search) |
| AI | Google Gemini (embeddings + chat) |

## ⚙️ How It Works

1. Each insurance record is turned into an embedding (768 numbers) and stored in MongoDB.
2. The user's question is turned into an embedding too.
3. Atlas Vector Search finds the most similar records.
4. Those records are sent to Gemini as context, and it writes the answer.

## 🚀 Setup

### 1. Clone the repo

```bash
git clone https://github.com/Rit014/ragChatBot.git
cd ragChatBot
```

### 2. Backend

```bash
cd backend
npm install
```

Create a `.env` file in `backend/`:

```
MONGO_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_gemini_api_key
PORT=3000
```

Seed the database, then start the server:

```bash
node seed/seed.js
node server.js
```

### 3. Vector index

In MongoDB Atlas, create a Vector Search index named `vector_index_test` on `rag.insurance_embeddings`:

```json
{
  "fields": [
    { "type": "vector", "path": "embedding", "numDimensions": 768, "similarity": "cosine" }
  ]
}
```

### 4. Frontend

```bash
cd frontend
npm install
npm run dev
```
